# IPl Cricketer Auction Manager for CSV files

## How to run it

Simply download the repo, then go in to repository and run main.py and voila!

## What is it ?

The IPL Cricketer Auction Manager is a Python-based, menu-driven application that uses CSV files to manage cricketer records. It allows users to search for cricketers by name, filter players by auction price or IPL team, add new records, update existing records, delete records, and sort cricketers by age, number of IPL matches, or auction price.
This application was a way for me to practice manipulation of data in csv files.
